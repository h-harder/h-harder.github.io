Connect Bookpost

The helper lets the converter send the finished book to Readest’s official Send page. You sign in there. Bookpost never asks for a Readest password.

  1. Download the helper ZIP and unzip it into a folder you’ll keep.
  2. Open chrome://extensions (or edge://extensions). Turn on Developer mode.
  3. Choose Load unpacked and select the folder containing manifest.json.
  4. Return to this page and reload it. Choose your ACSM file and press Continue to Readest.
